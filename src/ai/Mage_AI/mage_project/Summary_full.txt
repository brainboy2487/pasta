MAGE Project — Consolidated Documentation Summary and TODO

1) Executive summary
- Project: MAGE (Markov Answer Generation Engine). CPU-first deterministic inference engine using a Tiered Stochastic Tensor Framework and a bounded‑operation Answer Parser (TAP) with a strict Rule‑42 parse budget.
- Language & build: C11, POSIX, Makefile/CMake; Python used for tools and FFI.
- Key subsystems: TAP parser, Tiered generators (Hot/Warm/Cold), lazy block contraction, MPHF lookup, mmapped vector index, deterministic RP vectorizer, supervised subprocesses for tooling, logging/plugin/self-heal services, CLI/GUI presentation layers.
