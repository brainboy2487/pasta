Large Base Vocabulary file

format this file to a format the ai can use to respond to user prompt.


Format and Usage Notes

    Trigger: a single word or short phrase the AI should recognize in user input.

    Response: a short reply the AI can return verbatim or use as a template.

    Matching: triggers can be matched exactly, by substring, or via fuzzy matching depending on your recognizer.

    Customization: replace placeholders like [time], [date], [location], [name] with dynamic values from context.

    Priority: when multiple triggers match, prefer the longest or highest-priority intent.

    Extensibility: add synonyms, alternate phrasings, and language variants as needed.

Implementation Tips

    Normalization: lowercase triggers and strip punctuation before matching.

    Synonyms: map synonyms to the same trigger to reduce duplication.

    Context: use session context to disambiguate short triggers like open or close.

    Confidence thresholds: require higher confidence for destructive actions like delete or cancel.

    Confirmation: for actions that change data, ask for explicit confirmation before executing.
